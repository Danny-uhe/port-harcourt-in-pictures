# Port Harcourt In Pictures

A modern React-based media and brand promotion platform built for Port Harcourt’s leading lifestyle and entertainment community. The website showcases social media influence, audience engagement, brand campaigns, nightlife, restaurants, events, and local business promotions through a visually immersive and responsive user experience.

## Features
- Modern responsive UI/UX
- Animated hero sections
- Brand promotion showcase
- Social media engagement highlights
- Mobile-friendly design
- Smooth scrolling and interactive components
- Optimized performance

## Technologies Used
- React
- JavaScript
- CSS / Tailwind (if used)
- Vite (if used)

## Purpose
The platform was designed to help businesses, brands, restaurants, and event organizers reach Port Harcourt’s highly engaged online audience through digital media exposure and community-driven marketing.
